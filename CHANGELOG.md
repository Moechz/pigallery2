# Changelog

All notable user-visible changes to the PiGallery2 TOS application package.

## 3.5.2-1 — 2026-11-14

### Added
- First release. PiGallery2 (`bpatrik/pigallery2:3.5.2`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8050 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/pigallery2docker/`.
